# Médiathèque

Déposez ici les images référencées depuis *Administration → Médiathèque*.

Le champ « Adresse » attend un chemin relatif à ce dossier, par exemple
`/media/hotel-de-ville.jpg`. Le texte alternatif est obligatoire : il est lu par
les synthèses vocales et doit décrire ce que montre l'image.
