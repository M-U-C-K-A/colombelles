# Documents en téléchargement

Déposez ici les fichiers référencés depuis *Administration → Publications*.

Le champ « Adresse du fichier » attend un chemin relatif à ce dossier, par
exemple `/documents/budget-primitif-2026.pdf`.

Les documents du jeu de données initial sont des exemples : leurs fichiers ne
sont pas fournis. Remplacez les fiches correspondantes ou déposez les vrais
documents sous les mêmes noms.
